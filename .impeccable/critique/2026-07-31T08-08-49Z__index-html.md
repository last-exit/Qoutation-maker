## Design Specificity Verdict

**Strongly specific where the work happens; generic on Home.**

The Smart Matcher card is a purpose-built decision object — similarity chip, venue, elapsed-years chip, and an Original/Adjusted rate pair. No generic CRM has an elapsed-years chip because no generic CRM inflates historical rates. The Annual Markup slider sits above the search box rather than in settings because in this workflow markup is a search parameter, not a preference. AED and VAT 5% are first-class, and `UNIT_OPTIONS` is an events-fabrication vocabulary. The "borrowed photo" badge shows someone understood that sending a client the wrong backdrop is a business problem.

Home is the exception: four equal action cards over six stat tiles is stock admin furniture, and "Chronological Range" / "Max Valuation" are metrics nobody quoting an event has needed.

**Deterministic scan:** `detect.mjs --json index.html` → exit 2, **1 finding**: `flat-type-hierarchy` (warning) at `index.html:127` — "Sizes: 9.5px, 10.5px, 11px (ratio 1.2:1)". Scope-limited to inline styles, but independently corroborated: **14 distinct rendered sizes, 12 packed between 8.5px and 14px**, adjacent ratios ~1.03–1.06.

**Visual overlays:** not available — the Browser pane is not displayed, so screenshots and the injected overlay flow both fail. Evidence was gathered instead via accessibility tree, computed styles and a purpose-written WCAG contrast engine (validated against white/black = 21.00 and #767676/white = 4.54).

## Priority Issues

### [P0] The Annual Markup is a no-op for 76% of the catalogue — while claiming otherwise
`adjusted_rate = rate * (1 + markup) ** elapsed_years`. Measured against the live index: **304 of 401 items are dated 2026, so `elapsed_years = 0` and the multiplier is exactly 1.0.** The card still renders the label "ADJUSTED (9%)" above an identical number. The one place the product's core idea should be visible is where it silently does nothing.
**Fix:** Either prorate by fractional years (`(now - quote_date).days / 365.25`) so a six-month-old quote gets ~half the annual uplift, or suppress the "Adjusted" column entirely when the multiplier is 1.0 rather than printing a claim the number contradicts.

### [P0] "Generate Quotation" has no guard rail before a client-facing document
Verified live: the button is enabled with client `"Donut"` (a hardcoded value at `index.html:164`, not a placeholder), empty venue, description "Custom Event Production Item", and rate 0. Qty and rate have no `min` — `-5 × -100` produced **+500.00 AED** silently. `validity_days = 0` becomes 14 via `parseInt(...) || 14`. Unchecking both formats silently forces xlsx.
**Fix:** Remove the `Donut` default; add `min="0"`; gate the button on a pre-flight check; replace the immediate write with a confirmation sheet showing client, venue, item count, grand total, destination folder, and explicit warnings for zero-rate rows and empty venue.

### [P0] The application is not operable by keyboard
Both assessments converge: **27 of 44 clickable elements are `<div>`/`<span>` with `onclick`**, and B measured `navTabsInTabOrder: 0` — all four primary nav tabs are `tabIndex=-1`. Also unreachable: history status filters, image-picker tabs, both modal close buttons, and every draft row's set-image and delete control. **8 `<label>` elements, 0 with `for`** → 12 inputs announce as unlabelled. `aria-live`: 0. `role="dialog"`: 0.
**Fix:** Convert `onclick` divs to `<button type="button">`; add `role="tablist"/"tab"/aria-selected` with arrow traversal; associate every label; add one `aria-live="polite"` region for toasts.

### [P1] Closed modals stay in the tab order, exposing a destructive action
`.modal-overlay` uses `opacity: 0; pointer-events: none` but keeps `visibility: visible` (`style.css:519-523`). `#folder-path-input` and `#sync-btn` remain focusable while hidden — `pointer-events` does not block keyboard activation, so **Enter on an invisible "Sync & Build Index" starts a full Drive re-index.**
**Fix:** Add `visibility: hidden` to `.modal-overlay` and `visibility: visible` to `.open`; then add focus trap and focus restore.

### [P1] `--text-muted` fails WCAG AA in both themes — every field label in the app
Both assessments computed this independently and agree. All failures trace to one token, `rgb(139,133,120)`:

| Ratio | Selectors | Size |
|---|---|---|
| 3.02 | `.cmdk`, `#view-history thead th` | 11 / 9.5px |
| 3.13 | `#page-eyebrow` | 10px |
| 3.36 | `.field-label`, `.stat-label`, `.home-action-desc`, all `.empty-state p` | 8.5–11.5px |
| 3.51 | `kbd.kbd-hint` | 9.5px |
| 3.11 | success-modal PDF-failure warning | 11px |

Dark theme mirrors this at 3.22–3.70, and adds `.seg.active` (white on `--accent`) at **3.96:1**.
**Fix:** Darken `--text-muted` to ≈`#6b6559` (light) / lighten to ≈`#9a948a` (dark); raise `.field-label` and `th` from 9–9.5px to 11px.

### [P2] Rate adjustment silently loses money and destroys focus
Verified: 450 → `+10%` → 495 → `-10%` → **445.50**, permanently, with no reset. Separately `adjustRate()` calls `renderDraft()`, which rebuilds the whole list — active element becomes `BODY`, losing caret and scroll on every nudge.
**Fix:** Store `baseRate` and compute from a cumulative percentage with a click-to-reset chip; patch only the changed row.

## Persona Red Flags

**Sam (accessibility-dependent):** Cannot complete the primary flow at all — reaching a tab, deleting a mis-added row, and dismissing the success modal are all non-focusable. The stylesheet contains exactly **three** `:focus` rules, one of which is `outline: none`. Ironically the splitter (the least important control) has the app's only custom focus indicator. Meaning is carried by colour alone in three places (status dot, warning-vs-error banners, discount amount). **8 animation selectors, zero `prefers-reduced-motion`.**

**Alex (power user):** No keyboard route between views — the single most frequent action requires the mouse. Focus theft on every rate nudge. No multi-select on matches, no bulk rate adjustment. `Ctrl+Enter` fires `compileQuote()` with no confirmation, making the fastest path also the least reversible.

**Riley (stress tester):** Negative qty × negative rate = positive subtotal. `+10%/-10%` doesn't round-trip. Discount over-cap is clamped silently. Draft `<textarea rows="2">` has `resize: none`, so a long fabrication spec is unreadable without leaving the app.

## Minor Observations

- **`#segpill` sits +4px right of the tab it marks**, on all four tabs (measured: +4.0/+4.4/+4.2/+3.8px). `positionActiveTabPill()` sets `translateX(active.offsetLeft)` while `.segpill` CSS already has `left: 4px` — the offset is counted twice.
- **`::selection` is nearly invisible in light mode** — `--accent-soft` is a 9% tint. Raise to ~22–25% alpha.
- **Splitter ARIA is incomplete** — `role="separator"` + `aria-valuenow` with no `aria-valuemin`/`aria-valuemax`.
- **Heading structure is broken** — compiler has an H2 with no H1; review and history have *zero* headings.
- `.pct-btn` is 18.8px tall, checkboxes 13×13, and `#markup-slider` is **4px** tall — all under the 24×24 minimum.
- `toast` has no `role="status"`; `mouseenter` clears the dismiss timer but `mouseleave` never restarts it.
- **No horizontal overflow in any of 12 view×viewport combinations** — responsive behaviour is genuinely clean.
